Features

Everything a language toolchain needs

From tokenization to full AST construction, Sysbase handles every stage of the parsing pipeline with surgical precision.

Zero-Copy Parsing

Borrows directly from your source string — no intermediate heap allocations during tokenization or AST construction.

Incremental Parsing

Re-parse only the changed subtree on edits. Ideal for language servers and live editors with sub-microsecond re-parse times.

Fault-Tolerant Recovery

Never aborts on syntax errors. Produces a partial AST with structured diagnostics so editors can keep working mid-edit.

Dual-Language Support

A single unified API surfaces both Nexis (systems) and Seaphire (scripting) grammars with shared visitor and walker traits.

Structured Diagnostics

LSP-compatible error spans with source-location metadata. Plug directly into VS Code, Helix, or any Language Server Protocol client.

WASM & FFI Ready

Ships as a standalone WASM module with a C FFI layer. Embed in browsers, Node.js, Python, or any native host with zero fuss.

Languages

Nexis and Seaphire, first-class

Two languages, one engine. Sysbase ships grammar definitions, AST schemas, and test suites for both.

⚡ Nexis

Systems Language

Statically typed, compiled to native code. Designed for performance-critical applications with a clean, expressive syntax inspired by Rust and Swift.

🌊 Seaphire

Scripting Language

Dynamically typed, interpreted with optional type hints. Terse ML-inspired syntax ideal for configuration, tooling, and rapid prototyping.

How it Works

Four stages, one fast pipeline

From raw source to typed AST in a single pass with structured error recovery at every stage.

1

Lexer

Tokenizes the raw source string into a flat token stream. Zero allocations — tokens are byte-range slices.

→
2

Parser

Recursive-descent Pratt parser constructs the CST with precise span information and error node insertion.

→
3

AST Lowering

CST is lowered to a typed AST, desugaring syntax constructs and validating grammar constraints.

→
4

Output

Returns a typed AST root, a flat diagnostic list, and optional token stream for tooling consumers.

→

Visitor API

Implement the Visitor trait to walk every node type with full type safety.

Span Metadata

Every AST node stores byte-range spans for precise IDE integration.

Serialization

Serialize the AST to JSON or a compact binary format with serde support.

Mutation

Ecosystem

Built for the whole toolchain

Sysbase ships with everything you need to build editors, linters, formatters, and compilers.

LSP Server

Drop-in language server with hover, go-to-definition, completions, and real-time diagnostics out of the box.

Formatter

Opinionated, configurable code formatter with idempotent output. Compatible with both Nexis and Seaphire.

Lint Engine

Rule-based linting API. Write custom lint passes over the typed AST with structured fix suggestions.

Symbol Index

Build a workspace-wide symbol index for fast cross-file reference resolution and rename refactoring.

Plugin API

Extend the parser with custom grammar rules or AST passes using the stable plugin trait interface.

GitHub Action

Official CI action for syntax validation, linting, and formatting checks with annotated PR feedback.
